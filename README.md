For this project, I reviewed Artemis Financial's web application to identify security vulnerabilities and recommend ways to improve it. I think I did well identifying problems such as hard-coded database credentials, missing input validation, and error handling that could expose sensitive information. Secure coding is important because it helps protect customer information, reduce security risks, and maintain trust.

I also reviewed the Java code manually to identify security problems. I recommended removing hard-coded credentials, improving input validation and error handling, and limiting database permissions. These recommendations would add layers of security. In future projects, I would use manual code reviews and dependency scans to assess vulnerabilities.
